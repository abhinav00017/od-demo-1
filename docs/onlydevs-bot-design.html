onlydevs bot

One chat assistant for every business we build for. Design draft, 15 Nov 2026. Nothing is built yet.

1. One bot, a different face on every page

The same bot sits on every page. Each page tells it which business it belongs to, so it answers as that business.

The admin face appears only when the owner is really logged in. A visitor can never switch it on.

2. What happens to one message

Every message, on every page, goes through the same five steps.

Example: a patient types "Can I come Friday evening?" on the clinic site. The bot loads the clinic's profile, sees a visitor, decides to book, books the visit in the clinic's system, and replies.

3. How it grows

To addWhat we do
A new businessWrite its profile: name, hours, services, prices, which actions it may take. Put the chat bubble on its pages.
A new pagePut the chat bubble on it and say which business it belongs to.
A new actionBuild it once, for example "take an order". Any business can switch it on.
A new number, like revenueAdd the field to the database and one line to the list of measures. The owner can ask about it straight away.
A different AI modelChange one setting. Today it is Gemini Flash, free, for demos only.

4. Rules every bot follows

  • It only talks about its own business and politely declines anything else.
  • It never invents a price, a time or a promise. When unsure, it hands over to staff.
  • One business's bot can never see another business's data.
  • Business numbers only for a logged-in owner. Owner questions only read; changes still need a confirm step.
  • Clinics: no medical advice. Emergencies are told to call 108 and the clinic.
  • Real clients move to a paid AI plan before launch, so their customers' chats stay private.
